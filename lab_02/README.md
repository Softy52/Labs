### Вывод

Лучший результат при оценке NDCG@10 показал метод Overlap — 0.7144.
BM25 с параметрами варианта 12 получил 0.6846, немного превысив
результат BM25 по умолчанию (0.6801).
Результаты показывают, что простое совпадение терминов может быть
эффективным на данном наборе данных.
При этом лексические методы имеют ограничения при обработке
синонимов, перефразированных выражений и языковых вариаций.
