**Группа:** ИНФА-231  
**Вариант:** 12

### Параметры варианта
- Random state: 112
- Размер корпуса: 750
- Минимальная длина токена: 3
- Основной оператор: OR
- BM25: k1 = 1.6, b = 0.70
- Метрика: NDCG@10

### Используемые методы
В лабораторной работе реализованы и сравнены следующие методы ранжирования:
- Random;
- Overlap;
- TF-IDF;
- BM25 с параметрами по умолчанию;
- BM25 с параметрами варианта 12.

### Результаты

| Метод | NDCG@10 |
|---|---:|
| Random | 0.4961 |
| Overlap | 0.7144 |
| TF-IDF | 0.6789 |
| BM25 default | 0.6801 |
| BM25 variant 12 | 0.6846 |

### Вывод

Лучший результат при оценке NDCG@10 показал метод overlap — 0.7144. BM25 с параметрами варианта 12 получил 0.6846, немного превысив результат BM25 по умолчанию. Анализ отдельных запросов показал, что на качество ранжирования влияют частота терминов, длина предложений и особенности английского языка. Лексические методы имеют ограничения при обработке отрицаний, синонимов и перефразированных выражений.
